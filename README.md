# Эмулятор UNIX-подобной командной оболочки — вариант 8

Графическое приложение на C# / Windows Forms (.NET 8), имитирующее интерактивную оболочку UNIX-подобной ОС. Виртуальная файловая система загружается из CSV. Все команды работают с копией данных в памяти; исходный CSV не изменяется.

## Возможности

- GUI-терминал с заголовком `Эмулятор - [username@hostname]`.
- Интерактивный ввод, обработка ошибок и команды `exit`, `help`, `pwd`, `whoami`.
- Команды `ls` и `cd` работают с виртуальными каталогами.
- Команды `tail`, `uniq`, `tac` читают содержимое файлов VFS.
- Команда `chown` меняет владельца записи только в памяти.
- Аргументы с пробелами можно заключать в кавычки.
- Параметры запуска: `--vfs <путь к CSV>` и `--script <путь к скрипту>`.
- Стартовый скрипт показывает введённые команды и вывод; выполнение останавливается при первой ошибке.

## Формат CSV

Заголовок: `path,type,content,owner`. Допустимые типы: `dir` и `file`. Папка-родитель должна быть описана в файле. Вложенные элементы задаются абсолютными путями от корня VFS. Для перевода строки в содержимом используйте последовательность `\n`. Кавычки CSV экранируются удвоением.

## Сборка и запуск (Windows)

Установить .NET 8 SDK, открыть PowerShell в корне репозитория и выполнить:

```powershell
dotnet build .\ShellEmulator\ShellEmulator.csproj
dotnet run --project .\ShellEmulator\ShellEmulator.csproj
```

Запуск с VFS и стартовым скриптом:

```powershell
dotnet run --project .\ShellEmulator\ShellEmulator.csproj -- --vfs .\ShellEmulator\vfs\sample.csv --script .\ShellEmulator\scripts\demo.sh
```

## Команды

| Команда | Назначение |
|---|---|
| `ls [путь]` | Список элементов каталога |
| `cd [путь]` | Смена текущего виртуального каталога |
| `tail [-n N] файл` | Последние N строк (по умолчанию 10) |
| `uniq [-c] файл` | Удаление соседних повторяющихся строк; `-c` выводит число повторов |
| `tac файл` | Вывод строк в обратном порядке |
| `chown владелец путь` | Изменение владельца в памяти |
| `pwd` | Текущий виртуальный путь |
| `whoami` | Имя пользователя ОС |
| `help` | Справка |
| `exit` | Закрытие эмулятора |

## Тестирование

- `scripts/demo.sh` — тест команд и неизвестной команды.
- `scripts/test-minimal.sh` — базовые операции с минимальной VFS.
- `scripts/test-deep.sh` — вложенные каталоги и изменение владельца.
- `run-demo.bat`, `run-minimal.bat`, `run-deep.bat` — скрипты Windows для запуска эмулятора с разными параметрами и VFS.
- `vfs/sample.csv`, `vfs/minimal.csv`, `vfs/deep.csv` — варианты виртуальной файловой системы.
